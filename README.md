# AI Fandom Quiz Game

A Pygame-based quiz game upgraded from a notebook project into an interactive desktop game with local LLM support using Ollama.

## Features

- Pygame UI
- Category selection
- Difficulty selection
- Timer-based questions
- Score system
- Local leaderboard
- AI hints using Ollama
- AI explanations using Ollama

## Tech Stack

- Python
- Pygame
- Ollama
- llama3.2

## Run

```bash
brew install ollama
ollama serve
ollama pull llama3.2
